The problem

AI made content easy. It didn't make the next marketing decision obvious.

Campaign metrics show what happened. They don't answer the questions that shape the next campaign:

  • Who should we target next?
  • Which channel deserves another test?
  • Which message should change?

SignalLoop explores whether AI can help make that call from measured evidence, without letting the model invent the analytics underneath. It's a hypothesis I'm testing with product marketers, not a validated finding.

The model

One decision, split three ways.

CODE

What happened?

Measures reach, clicks and CTR, and checks whether a difference is real.

→
MARKETING AGENT

What should we test next?

Picks the audience, channel and message, citing the evidence.

→
CONTENT AGENT

What should we create to test it?

Writes the variant within brand and channel rules.

HUMANControls segmentation, positioning, objectives and constraints, and approves every step.

Each test runs against the best version so far, and its result feeds the next decision.

One experiment, end to end

A Ramp scenario, from baseline to the next decision.

Recorded from one run of the demo. Performance numbers are simulated; the recommendation and content are the agents' output from that run.

  1. BaselineWhat happened?
    SIMULATEDCODE

    Controllers responded best: 9.8% CTR (151 of 1,548 reached). For them, email had the highest CTR (14.6%), while LinkedIn delivered more clicks per experiment (63 vs 35).

  2. InsightWhat did the evidence indicate?
    CODE

    A trade-off between reach (LinkedIn) and response (email), with three of four messaging angles still untested on Controllers. The objective, product consideration, favors response.

  3. RecommendationWhat should be tested next?
    AI · MARKETING AGENTMARKETER APPROVES

    Controllers × email × real-time visibility, as a customer story. The agent named the trade-off (fewer clicks than LinkedIn, stronger response) and rated its confidence medium.

  4. ContentWhat did the Content Agent produce?
    AI · CONTENT AGENTMARKETER APPROVES

    An email, "Stop waiting for the month-end surprise", with the preview text "Gain total visibility into company spend as it happens." and a "See how it works" button.

  5. ExperimentWhat gets compared?
    SIMULATED RESULT

    The new email against the best version so far, "Close the books without chasing receipts", split 50/50: 7.3% (9 of 124) vs 11.8% (14 of 119).

  6. LearnWhat happens next?
    CODEAI

    Too close to call. 23 clicks can't support a 4.5-point conclusion; a winner needs 20+ clicks on each side and a significant gap. The best-so-far email stays the control, and the next recommendation treats the result as uncertainty: retest, or try an untested angle.

A dashboard would show the new email losing. SignalLoop waits until the evidence can support that call.

Why I designed it this way

AI interprets the evidence. It never manufactures it.

Keep measurement deterministic

Decision
Metrics and significance checks run in code; the agents only read the results.
Why
Arithmetic and significance calls have to be reproducible and auditable.
Trade-off
Less flexible than letting a model explore raw campaign data.

Separate strategy from execution

Decision
The Marketing Agent chooses the experiment; the Content Agent executes it.
Why
Content generation can't quietly change the audience or the hypothesis, and strong copy can't hide a weak choice.
Trade-off
Two AI steps instead of one.

Require evidence before a recommendation

Decision
Recommendations must cite campaign metrics the agent retrieved; code rejects anything else.
Why
A PMM should be able to trace a recommendation to its numbers before acting on it.
Trade-off
Some responses are rejected and retried.

Keep a marketer accountable

Decision
The marketer approves the recommendation, then the content, and every test runs against the best version so far.
Why
Positioning, claims and budget stay a human call, and every result gets a fair comparison.
Trade-off
Slower than an autonomous loop.

    How the constraints are enforced.

    For technical reviewers; the case study above doesn't depend on these details.

    Architecture
    PageStatic case study and demo. Opening the page makes no API calls; only running a step does.
    APINetlify Functions for running an experiment, getting a recommendation, creating content and starting over, with rate limits and daily caps.
    ModelsGroq (openai/gpt-oss-120b) first, with Gemini (gemini-3.1-flash-lite) as the fallback when Groq is rate-limited or fails.
    CRMHubSpot API: fictional contacts, a persona property and one audience list per segment.
    StorageNetlify Blobs for each visitor's experiment history.
    How the agents are constrained

    Marketing Agent

    • Reads metrics only through read-only tools
    • Must cite 2 to 5 metrics it actually retrieved
    • The channel must be available to the chosen audience
    • The test must differ from the current best version
    • Confidence capped at medium before three experiments

    Content Agent

    • Cannot change the audience, channel or messaging angle
    • No numbers or statistics, so no unverifiable claims
    • Can't reuse a topic already tested with the audience
    • Personalization by first name only, and only in email
    • No links or placeholders; the call to action is a button

    Output that fails a check is sent back once with the errors, then to the fallback model, and otherwise fails visibly. Unchecked output is never shown.

    Statistics
    • A winner is called only with at least 20 clicks on each side and a two-proportion z-test at about 95% confidence (|z| ≥ 1.96).
    • Efficiency leader = highest CTR. Volume leader = most expected clicks per experiment. The campaign objective decides which matters more.
    • Audience results are pooled across experiments and compared with the other audiences.
    Simulated performance model

    Each audience has a hidden response profile by channel, messaging angle and content type, with random variation in every run. The agents see only measured results, so a good recommendation has to be inferred from evidence.

    The takeaway

    SignalLoop reflects how I approach AI-enabled product marketing.

    • Identify the decision that actually matters.
    • Separate measurement from interpretation.
    • Automate what should be deterministic.
    • Use AI where judgment adds value.
    • Keep a person responsible for the final call.
