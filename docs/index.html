Why SignalLoop exists

Campaign evidence should shape the next campaign decision.

Campaign metrics show what happened. On their own, they don't answer the questions that shape the next campaign:

  • Who should we target next?
  • Which channel deserves another test?
  • Which message should change?

The idea: connect campaign evidence to the next audience × channel × message decision, without letting AI invent the analytics underneath. It's a hypothesis I'm testing with product marketers, not a validated finding.

Learning

An inconclusive test still changes the next campaign.

What we learned

The real-time visibility treatment did not outperform the current control. With only 5 clicks on the treatment, the evidence doesn't justify replacing the control, or ruling real-time visibility out for good. Keep the control and test a different message.

How that changes the next campaign AI · MARKETING AGENT
Stays the same
  • Audience: Controllers
  • Channel: Email, still their efficiency leader (11.0% CTR)
  • Current control: "Close the books without chasing receipts"
Changes
  • Message: real-time visibility → cost control
  • Format: customer story → thought leadership

Why: the last test was inconclusive on low volume, so the agent moved to a message Controllers haven't seen. Cost control has a 6.9% CTR across all segments (144 clicks of 2,076 reached). Confidence stays medium.

How SignalLoop works

Each part of the loop has one job, and AI never produces the numbers.

CODEDeterministic analytics
Baseline performance and readout

Calculates CTR, pooled results, channel leaders and whether a gap is big enough to act on, so every number is reproducible.

AIMarketing Agent
Next-best test, and why

Chooses the audience, channel and message from measured results, and must cite the metrics it used; code rejects anything else.

AIContent Agent
Creative execution

Writes the variant within brand and channel rules. It can't change the audience, channel or hypothesis.

SIMULATEDResponse simulator
Campaign response

Produces reach and clicks from a hidden model the agents never see.

STOREDCampaign history
Learning

Keeps every experiment, so campaign learning informs the next optimization.

A marketer approves the recommendation and the content before anything runs, and every test runs against the current control.

Implementation details, for technical reviewers
Architecture
PageStatic case study and demo. Opening the page makes no API calls; only running a step does.
APIVercel Functions for running an experiment, getting a recommendation, creating content and starting over, with per-visitor rate limits and daily caps.
ModelsGroq (openai/gpt-oss-120b) first, with Gemini (gemini-3.1-flash-lite) as the fallback when Groq is rate-limited or fails.
CRMHubSpot API: fictional contacts, a persona property and one audience list per segment.
StorageUpstash Redis for each visitor's experiment history and the usage limits.
How the agents are constrained

Marketing Agent

  • Reads metrics only through read-only tools
  • Must cite 2 to 5 metrics it actually retrieved
  • The channel must be available to the chosen audience
  • The test must differ from the current control
  • Confidence capped at medium before three experiments

Content Agent

  • Cannot change the audience, channel or messaging angle
  • No numbers or statistics, so no unverifiable claims
  • Can't reuse a topic already tested with the audience
  • Personalization by first name only, and only in email
  • No links or placeholders; the call to action is a button

Output that fails a check is sent back once with the errors, then to the fallback model, and otherwise fails visibly. Unchecked output is never shown.

Statistics
  • A winner is called only with at least 20 clicks on each side and a two-proportion z-test at about 95% confidence (|z| ≥ 1.96).
  • Efficiency leader = highest CTR. Volume leader = most expected clicks per experiment. The campaign objective decides which matters more.
  • Audience results are pooled across experiments and compared with the other audiences.
Simulated performance model

Each audience has a hidden response profile by channel, messaging angle and content type, with random variation in every run. The agents see only measured results, so a good recommendation has to be inferred from evidence.

    What is real vs simulated

    Simulation runs the workflow. It isn't a business result.

    • REAL INTEGRATIONHubSpot API creates fictional contacts and audience lists.
    • AI-GENERATEDMarketing Agent recommendation and Content Agent output.
    • DETERMINISTIC CODECTR, aggregation, comparison and significance calculations.
    • SIMULATEDCampaign delivery, reach and clicks.

    Simulation lets the full optimization workflow run without presenting fictional performance as a business result.

    The takeaway

    SignalLoop reflects how I approach AI-enabled product marketing.

    • Identify the decision that actually matters.
    • Separate measurement from interpretation.
    • Automate what should be deterministic.
    • Use AI where judgment adds value.
    • Keep a person responsible for the final call.
